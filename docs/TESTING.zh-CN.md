## 自动化检查

```sh
uv sync
uv run pytest
uv run ty check src tests
```

现有测试覆盖纯窗口算法、恢复参考、模型持久化、浮空脉冲、策略注册、暂停确认、恢复辅助及事件队列。单元测试通过不证明真实运动安全，尚未宣称完成打印机至 Hermes 的实机验收。

## 实机验收（记录实际测量）

| 测试 | 通过标准 |
|---|---|
| 基准与健康打印 | 代表性速度/PA/温度无误判；模型通过验证 |
| 统计/绝对检测 | 两者暂停且捕获来源与轨迹，不超过硬件限值（优先安全模拟信号） |
| 人工诊断 | 安全停靠、标定力限制、正确 E 速度及长度；低力/混合/超限保持暂停 |
| 非首层恢复 | 正常诊断；正确恢复路径；健康窗口及重试限制 |
| 首层补偿 | 实测正向间隙；PAUSE_STATE 恢复、累计限制及清理 |
| 失败/取消/重启 | 无过期回调或意外恢复；检查自有偏移 |
| 远程链路 | SQLite 每源 ID 一次；负载一致；生命周期独立；重连及 Hermes 投递 |

按阶段测试，相应验收通过前保持自动功能关闭。不得通过真实过载高温系统进行试验。记录固件 SHA、模块 SHA、配置、材料、温度、力上限与结果。未完成：队列运动即时取消、完整 ADC 存档、实机验收。
