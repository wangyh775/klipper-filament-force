# Event reliability / 事件可靠性

Schema 1 remains compatible. New native event filament_force:sensor_fault and status journal kind sensor_fault are emitted by the protection watchdog on stale load cell stream or unavailable baseline. Fields: reason, source=watchdog, sensor, tool, sensor_last_sample_age_s (seconds or null), baseline_locked (boolean), window (bounded calibrated trace, possibly empty). A standalone sensor fault begins an incident; during recovery it retains incident linkage. recovery_failed now passes through one failure-transition helper, includes previous_state, and is emitted when entering FAILED or changing its reason. Repeated identical failure transitions are not republished until state changes. The recovery_failed state-transition event also follows sensor_fault; consumers may handle them independently. Native listeners are deferred as before; no remote delivery gates local PAUSE. Shutdown telemetry is best effort; RAM journal can disappear on restart.

Schema 1 保持兼容。看门狗检测传感器断流或基准无法建立时新增原生 filament_force:sensor_fault 及队列 sensor_fault，字段 reason、source=watchdog、sensor、tool、sensor_last_sample_age_s（秒或 null）、baseline_locked（布尔值）、window（有限标定轨迹，可为空）。独立传感器故障新建关联 ID，恢复过程保留关联。所有 FAILED 转换统一发布 recovery_failed，新增 previous_state；进入 FAILED 或失败原因变化才发出，相同状态/原因不重复。sensor_fault 与 recovery_failed 表示独立保护事件及状态转换，消费端可分别处理。远程投递不影响本地暂停；停机事件尽力传输，内存队列重启可能丢失。
