# 统一堵头二次诊断与有限恢复

简体中文 | [English](diagnostic-recovery.md)

## 设计约束（实验功能）

保留现有速度分组统计受力模型、连续异常确认和独立绝对受力保护。不增加机械回弹、周期性特征识别、独立浮空模型或自动压力提前调节。

统计高力、绝对受力超限及持续模型验证不匹配进入统一堵头流程。绝对力超限代表紧急过载，而不证明喷嘴堵塞；诊断前先暂停。断料保留独立暂停流程。

两套弱定义 G-code 策略：

- FILAMENT_FORCE_JAM_ACTION：二次诊断前准备；保留原接口并增加 SOURCE、E_SPEED。核心保证先暂停。默认不指定停靠位置。
- FILAMENT_FORCE_CONFIRMED_JAM_ACTION：重复浮空高阻力时调用；默认提示并保持暂停。自定义通知或清堵需独立验证，不得直接恢复打印。

第一策略必须确保喷嘴远离床面和打印件、运动路径安全、废料妥善收集。自动诊断需要 M400 后显式确认 FILAMENT_FORCE_DIAG_READY CLEARANCE=1。默认不授权。仍支持人工确认后执行 FILAMENT_FORCE_DIAGNOSE CLEARANCE=1。

## 状态机

MONITORING（监控）→ PREPARING（暂停准备）→ WAITING_DIAGNOSIS（等待诊断）→ DIAGNOSING（诊断）→ CONFIRMED_JAM（确认高阻力）/ WAITING_RECOVERY（等待恢复）/ FAILED（失败暂停）。

启用自动恢复后，WAITING_RECOVERY → RESUMING（恢复）→ VERIFYING（验证）→ MONITORING 或 FAILED。诊断与恢复验证期间冻结正常模型；取消、结束、新任务或关闭时清除临时恢复状态。保留打印过程绝对力保护与诊断脉冲的峰值限制。每次故障只诊断一次，限制单任务自动重试次数，连续健康窗口后才结束验证。层数未知、模型未学习、基准不稳定、样本缺失、温度改变或恢复条件不可靠时不得自动恢复。

## 浮空二次诊断

复用短距离挤出脉冲与现有速度组打印模型，不对故障试验数据学习。diagnostic_speed 默认固定 3 mm/s，可通过 CFG 在 0.5–6 mm/s 内设置；diagnostic_match_speed 默认 False，开启后匹配故障时速度且不超过配置值。实际脉冲长度为 max(配置最小长度, 速度×0.5 s)，最大 3 mm；默认 1.5 mm/次。默认三次共 4.5 mm。

短脉冲中段均值与打印窗口均值并不完全等价。正常受力只说明诊断条件下未发现明显高阻力，不证明真实出料。没有可用模型时采用明确标定的人工上下限，否则不确定；人工上下限不授权自动恢复。保留诊断速度与故障速度偏差不超过 20% 且属于相同速度组的自动恢复限制。力限制触发停止后续脉冲，不能即时取消已排队运动，并不直接调用真性堵头策略。

## 恢复及首层 Z 补偿

首层采用正向间隙增量，默认 0.02 mm/次，最多三次且累计不超过 0.06 mm，检查冷却间隔、归零与层数。恢复后比较归一化受力异常程度，达到健康窗口数则结束；高力仍持续但改善至少 15% 且有预算才允许再次诊断和补偿。无改善、低力或严重超限时暂停。

非首层不调整 Z，诊断正常且满足恢复条件时允许有限次恢复并验证。PA 瞬态、加速度和热端流量能力可能导致假性堵头，不自动调整工艺参数。恢复是显式可选功能。Kalico PAUSE_STATE 恢复会覆盖当前 Z offset，因此调整保存状态中的 Z 基准与恢复位置，要求已验证的 resume_gcode 和真实设备运动路径；不得猜测停靠点、间隙、方向或出料证据。

## 验证与限制

覆盖两种检测来源、两套策略、缺少浮空授权、未学习模型、高力/低力/混合/缺样本结果、重试上限、验证超时、取消/重启、过期回调以及模型保留。Z 偏移必须在兼容恢复路径中验证，并避免撤销用户自己的偏移。自动诊断、恢复与首层补偿默认关闭，须先完成 CI 与实机验证。

实现位于实验分支；自动诊断要求明确安全浮空确认，自动恢复要求显式并实测兼容的 resume_gcode。参见 [中文使用说明](../README.zh-CN.md)、[示例配置](../filament_force.cfg) 与 PR 验证状态。
